# 引き算と一貫性

## 削るもの

足したくなったら、先に既存の要素を1つ外せないかを考える。外した情報は、話す原稿に「口頭のみ」として残す。

| 削るもの | 理由 |
|---|---|
| ページ下部のメッセージ・注記・結論の一文 | 読まれない。結論はタイトルとリードで伝わる。補足の論点は本文の流れに入れる |
| 図の中の補記、リードと重なる説明、見出しと重なる「右図はイメージ」 | 重複 |
| 列見出しの下の定義の小行、「言える範囲」、空欄の理由の注記 | 無駄な説明テキスト。見出しは1段・太字だけ |
| 番号による図と説明の対応づけ（図に①②、右に番号順の説明） | 直感的でない。説明は指す要素の隣に置く |
| 副題、カッコ書き、章扉の説明文 | 章扉は番号と題だけ |
| 自明なラベル（「社内規定の流れ」「本件では：」） | 見れば分かる |
| AI が補った項目の印、管理用の番号 | 不要 |
| 意味の説明できない記号・色・線（★、等間隔の点、浮いた線、傾き） | 意味が伝わらない |
| 行見出しのアイコン | アイコンは意味を運ぶ位置にだけ置く |
| タイトルの冗長な語尾、「（案）」、情報源の表記 | 冗長 |
| ページの目的外の情報 | 1ページの目的は1つ |
| 前後と重なるページ、末尾のまとめのページ | 重複。送って読ませる報告書の冒頭の要約1枚は、これに当たらない |
| 当たり前の内容、説教くさい一文 | 弱い |
| 出典の注記 | 構成案の値には付けない。追加調査で持ち込んだ数値のページは1行の `source`、詳細へ飛ばしたい数値は1行のリンク |
| 細かすぎる精度（3日15時間）、幅のある値（3〜6か月）、合計 | なんとなくの粒度で足りる。曖昧な幅はやめて1つの値に丸める |
| 俯瞰の図の棒の中の数値、確度の行、「未設定」「要確認」 | 形で読ませる。元の値は別ファイルで持つ |
| 表のヘッダーと先頭列の塗り・色・太字の重ね | 目立たせる必要がない |
| 各セルで繰り返す同じ情報 | ヘッダー1か所に |
| 余計な論点を呼ぶ一言、内部情報、担当者名 | 不要な議論が生まれる。口頭へ |
| 濃紺塗りのラベル・矢羽・見出しブロック |  |
| 動画の尺・解像度・説明、動画ページの見出しとリード | 動画そのものが説明になる |
| 構成図の本筋でない区画 | ややこしくなる |

要素を削ったら、残りを空いた領域の中で置き直す。

## 削りすぎ（差し戻された状態）

| 状態 | 直し方 |
|---|---|
| 橋渡しのページを外して論理が飛ぶ（原因からいきなり対策へ） | 「何が必要だったか」のような橋渡しのページを足す |
| 前提なしに図や結論が出る | 指標は初出のリードで定義と数値をセットにする。後で再登場する図は、先に事実のページで素のまま見せる |
| 唐突に詳細が出る | 方法 → 当てはめの順に並べ替える |
| 塗りを抜いて線と文字だけにしたらスカスカ | 図を大きく、根拠の数値・ラベルを足し、近接・整列でまとめる |
| 「シンプルに」を文字の削減と取り違える | 情報量は保ち、装飾だけを減らす |
| すっきりさせるためにデータを図から抜き、ノートへ移す（2026-11-09 の v10） | データは図の中に注釈で残す。主役以外は灰・小さい文字で退かせる |
| 同じ形の帯やブロックを横に並べただけで、形が理解を助けていない | 差や関係が形に出る定番の図（折れ線、棒、比較の表など）に戻し、注釈で密度を上げる |
| 定番の形を目新しい形に置き換える（TAM・SAM・SOM の横長の楕円） | 見慣れた形（正円の入れ子）のまま、図の中の情報を増やす |
| 全体像の密度が足りない | 段階×観点の行を足して1枚で高密度にする |
| 表と文章だけで視覚的に分からない | 人・旗・✓×などの模式図やピクトグラムにする |
| 例を1つだけ出す | 該当する例は全部並べる |
| 1枚に詰めて知らない人に分からない | 2枚に分ける |
| ページに大きな空き | 箱を広げる、文字を一段上げる。次のページで埋まる前提の空きは残す |

## ページ間の一貫性

- 同じ役割のページは全章で同じ構造・同じ部品にする。独自の構造を持ち込まない
- 同じ図は同じ関数・同じ座標・同じ線の描き方で描く
- 同じ図を2ページで使うときは、図を動かさず・縮めず、前面に要素を重ねる（`components.md` の重ね技）
- 同じ問いが続くページは左の列を固定し、右側だけを変える。連続ページは「変更」ではなく「追記」で作る。引き継いだ行は灰、そのページで足した行は黒
- ページをまたぐ対応は同じ高さ・同じ順で1対1に置く
- ゲートなどの基準位置は全ページで同じ座標
- 読む向きは全ページで左→右
- 区分の名前・色・並び順をすべての図で同じにする
- 名称は資料全体で1つにし、変えたら目次・章扉・ミニ目次・参照・話す原稿まで一括で直す
- 用語を入れ子にしない（主因・根本原因・要因を並べない）。小見出しは抽象語ではなく対象の名前にする
- 同じ並びの中で文体・粒度・性質（行為か状態か）をそろえる
- 各章の1ページ目のタイトルは同じ接頭辞にする
- 型を流用しても、中身はその章のものにする（前の章の対策をそのまま写さない）
- 一度決めた見た目のルールは、同じ種類の全ページへ広げる
- リードはサイズ・太さ・位置・揃えを全ページで同じにする。長いときは文字を縮めずに言葉を縮める
- 他ページへの参照（P.番号）は、ページ番号の記録から最後に自動で入れる
