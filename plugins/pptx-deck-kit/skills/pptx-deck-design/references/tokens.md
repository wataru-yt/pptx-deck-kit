# デザイントークン

値は `assets/deck-parts.js` の定数と同じ。単位は特記がなければインチ、文字は pt。スライドは LAYOUT_WIDE（13.333×7.5）。

## 色

| 名前 | 値 | 用途 |
|---|---|---|
| ink | 002B5C | タイトル、見出し、主の文字、強調枠、主の矢印、番号丸、紺地の区切りページ |
| soft | 4A5568 | 説明文、Before の文、表の値、比較の基準列の見出し、章名、ラベル |
| gray | 8A8F99 | 補助の矢印、線・図形（文字に渡すと soft で描く。フッターは除く） |
| pale | B3B8C1 | 薄い線・図形（文字に渡すと soft で描く） |
| line | D9DDE3 | 細線 0.75pt、空枠の破線、画像・動画の枠 |
| tint | F4F6F9 | 標準の塗りブロック |
| tintStrong | E3EAF4 | 強調のブロック。1ページ1か所 |
| accent | B3261E | 問題、注意、赤枠、ゲートの破線、反省の番号、戻りの矢印、節目 |
| link | 0066CC | リンク・URL |
| before | EEF0F3 | Before パネルの面 |
| after | E4EDF8 | After パネル、「あるべき姿」の面 |
| bar | C9CED6 | 単系列の棒の標準色（主役の1本だけ ink） |

役割は固定する。濃紺＝主と強調、赤＝問題と視線誘導とゲート、灰＝参照と退かせる情報。

図の中だけの色:
- データの区分色は、はっきり違う色相で5つまで。名前・色・並び順を棒・凡例・ガント・内訳で共通にする。例（5区分）: AFC6A6／E5C47F／002B5C（白文字）／D3A39C／DADDE1
- 付箋: 黄 FFF1A6、ピンク FFD9E2、青 CFE6FF。文字 1D2433、選ばれていない付箋の文字 6B7280
- グラフの目盛線 EEEEEE、他社の線 979DA8

色のルール:
- 意味のない色分けをしない。同じ集合の中で1つだけ色を変えない
- 同じ図の中で同じ色を別の意味に使わない
- 濃紺の塗りの境界:

| 種類 | 濃紺で塗るか | 例 |
|---|---|---|
| データの印 | 塗ってよい | 棒、面、点、線、ガントの帯、人のピクト、区分色の 002B5C |
| ページの区切り | 塗ってよい | 紺地の区切りページ、番号丸 |
| 飾りの面 | 塗らない | 見出しブロック、ラベル、矢羽、パネル、カード、文字を載せる箱 |

- 単系列の棒の強調は、主役の1本を ink（002B5C）、他を bar（C9CED6）。主役が問題を示すときだけ赤の太枠にする
- 白抜き文字は、紺地の区切り、番号丸、濃紺のデータの印（帯・棒）の中だけ

## 文字

書体は Yu Gothic 1つ（数字の丸は Arial、パスとコードは Consolas）。太さは bold と regular の2段。

| pt | 用途 |
|---|---|
| 48 | 表紙の題 |
| 36 | グラフの見る所の値（`FOCUS_FS`） |
| 30 | 章扉・区切りページの題（26字を超えたら26） |
| 26 | ページタイトル、記号「≠」「＝」 |
| 22 | リード（`LEAD_FS`）、要点・箇条書きの見出し、円・ドーナツの主役の値と中央の合計、循環の中心の値（`FS_DISPLAY.num`） |
| 20 | 章扉の番号、星取の記号、図の中のやや大きい文字（`FS.lead`）、要点の説明・箇条書き、表の決め手の数値 |
| 18 | 名前・見出し（`FS.head`・`FS.block`）、表の値 |
| 16 | 本文、図中のラベル（`FS.body`）。ミニ目次、凡例、軸の目盛り、注（`FS.note`）。表の行の名前と列の見出し |
| 14 | 密な図だけ（スイムレーンの工程名） |
| 5.5〜6.5 | 付箋の本文（例外） |

- 主役の図の中で使うサイズは4段まで（タイトル26・リード22は別）。5段目が要るのは情報が多すぎる合図で、サイズを増やさず情報を減らす
- 図の中の文字（ラベル・軸・注記を含む）は soft 以上の濃さ、16pt 以上。`FS.body`・`FS.note` は 16pt、`FS.block`・`FS.head` は 18pt、`FS.lead` は 20pt（2026-11-24 に案Bへ上げた）。gray・pale・faint は線と図形の色で、文字に渡すと部品が soft に描き直す
- 1つのテキストの強調手段は1つ（太字か色か）。両方を使うのはページで唯一の強調だけ
- 行間: リード 1.2、ブロック 1.2〜1.3、密な表 1.05〜1.15。見出しと説明の間は 6pt の空行

## 線・影・透明度

- 細線は 0.75pt の line 色だけ。行の区切りの線は、記号や数字が主役で行数の少ない表に限る
- 破線: ゲート＝赤 3pt、最大の分岐点＝赤 3.5pt、他の会議＝灰 1pt、範囲＝soft 1pt、該当なしのセル＝line 0.75pt
- 枠: 強調＝ink 2〜2.25pt、問題＝accent 1.25〜2.25pt
- 影は前面に重ねる吹き出し・箱と付箋だけ（opacity 0.12〜0.18、blur 2〜8）
- 背景の図を薄くする白は transparency 18〜30

## 色の組を差し替える（テーマ）

`createDeck(pres, { theme: { … } })` で、色のトークンを差し替える（会社・個人の見た目として JSON に置くときは、下の「テーマの設定の項目」の `colors`）。キーは `ink`（文字）、`emph`（強調の枠・線・データの印・番号丸）、`dark`（区切りページの地）、`soft`、`gray`、`pale`、`line`、`faint`、`tint`、`strong`、`accent`（問題の赤）、`bar`。値は `#` なしの6桁。

- 既定は `emph` も `dark` も `ink` と同じ（濃紺1色）。`ink` だけを替えると、3つとも同じ色になる
- 文字を黒に近い色、強調を別の色にする例（動画の色にそろえた資料）: `{ ink: "151821", emph: "2F6BFF", dark: "111418", soft: "5C6575", gray: "9AA1AD", line: "E1E4EA", tint: "F5F6F8", strong: "E3EBFF", accent: "C5221F" }`
- 本文のページの地は、白か薄い無地にする。塗りブロック（`tint`）を白に、地を灰にする形は、白い箱を重ねる部品（スイムレーン）が見えなくなるので使わない。会社の背景・飾りは、下の「飾りの層」で敷く
- 1色の汎用アイコン（`icons/` の人・建物など）は濃紺で作ってある。文字の色を替えたら、同じ色に塗り直す

## 色の組を、題材に合わせて選ぶ（2026-11-24）

色は資料ごとに決める。指定がなければ、題材の分野と読み手から選ぶ。`createDeck(pres, { theme: "名前" })` か `{ theme: { emph: "強調の色" } }`。

| 名前 | 強調の色 | 向く題材 |
|---|---|---|
| `blue` | 2F6BFF | IT・ソフトウェア・スタートアップ |
| `teal` | 0E7C86 | 医療・ヘルスケア・公共 |
| `green` | 1F8A5B | 環境・農業・食品・サステナビリティ |
| `orange` | D9730D | 小売・消費財・飲食・教育 |
| `purple` | 6B4FD8 | クリエイティブ・エンタメ・AI |
| `slate` | 3D4A5C | 金融・法務・製造（控えめに） |
| `navy` | 002B5C | 落ち着いた報告書（文字も同じ濃紺） |

- 強調の色1つから、強調の塗り（白で薄めた色）と、区切りページの地（暗くした色）を作る（`themeFrom`）。文字は黒に近い色、退かせるものは灰
- 元になる素材（動画、サイト、ブランド）があれば、その色を `emph` に渡す
- 赤は問題の色（`accent`）。強調の色に選ばない
- 色は、強調の1色と灰だけで組む。区分を色で塗り分けるのは、グラフの区分だけ
- 選んだ色と理由を、build.js の先頭に書く

### 章ナビ（`nav`）

右上などに章の名前を並べ、今の章を目立たせる。章の名前は資料ごとに違うので、build.js の `createDeck` の `nav: [{ name, ch }]` に書き、章の始まりで `chapter()` か `setChapter()` を呼ぶ。形だけをテーマに書く。

| 項目 | 中身 |
|---|---|
| `style` | `"text"`（文字だけ）・`"underline"`（今の章に下線）・`"tabs"`（箱を並べる）・`"bar"`（全幅の帯）。`false` で出さない |
| `align` | `"right"`（既定）・`"left"`・`"justify"`（`x`・`w` の幅に等分） |
| `x`・`y`・`w`・`h` | 位置と大きさ（インチ） |
| `size` | 文字の大きさ（11〜18） |
| `color`・`activeColor` | 文字の色（ほかの章・今の章） |
| `fill`・`activeFill` | 箱・帯・下線の色 |
| `numbers` | `true` で章番号を付ける |

ページの種類ごとに違えるときは `master.<種類>.nav` に書く。build.js の `miniNav: false` で消せる。

### 飾りの層（`master`）

`content`（本文）・`cover`（表紙）・`chapter`（章扉）・`divider`（区切り）の種類ごとに書く。背景と飾りは PowerPoint のスライドマスターになるので、開いた後も1か所で直せる。

| 項目 | 中身 |
|---|---|
| `background` | 6桁の色、色のトークンの名前、画像のパス（PNG・JPEG。theme.json からの相対）、`{ color, image }` |
| `objects` | 飾り。`{ type, x, y, w, h, color, line, transparency, rotate, flipH, flipV }`。`type` は `rect`・`roundRect`・`ellipse`・`triangle`・`rtTriangle`・`line`・`image`（`path`）・`text`（`text`・`size`・`bold`・`align`・`valign`・`font`）など。`line` は `width`・`dash` も書ける |
| `boxes` | 文字の置き場所 `{ x, y, w, h, color, size, align, valign, bold, font }`。content は `section`・`title`・`lead`、cover は `title`・`sub`・`kicker`・`date`・`affil`・`logo`、chapter は `num`・`title`・`sub`、divider は `title`・`sub`。書いた項目だけ替わる |
| `footer` | `false` でその種類のページにフッターを描かない（背景に入っているとき） |
| `pageNumber` | `false` か、`footer.pageNumber` と同じ置き場所 |
| `nav` | その種類のページの章ナビ（`false` か `nav` と同じ形） |

```json
{
  "colors": { "emph": "1B6E4A" },
  "nav": { "style": "tabs", "y": 0.2 },
  "master": {
    "content": {
      "objects": [
        { "type": "rect", "x": 0, "y": 0, "w": 13.333, "h": 0.12, "color": "emph" },
        { "type": "image", "path": "logo.png", "x": 11.7, "y": 6.9, "h": 0.4 }
      ]
    },
    "cover": { "background": "cover-bg.png", "boxes": { "title": { "x": 0.8, "y": 2.4, "w": 8, "h": 1.2, "align": "left", "color": "FFFFFF" } } }
  }
}
```

部品は作るときに次を点検して警告する：文字が地の色・絵の上で読みにくい、飾りが文字や本文の領域に重なる、本文のページの地が濃いか派手、章ナビが飾りに重なる。濃い地の上の文字は、色の指定がなければ白にする。
